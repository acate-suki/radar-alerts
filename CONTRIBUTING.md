# Contributing

Thanks for contributing to `radar-alerts`.

## Conventions

- Editor rules live in `.editorconfig` + `.vscode/settings.json`.
- Content lives under `src/` as data: curated watchlists, sources, keywords, and rules — one area per folder, each with its own readme.
- Implementation work is tracked as issues (parents + children); keep issues focused.
- `test.yml` gates pull requests — keep it green.

## PR workflow

1. Branch from `main`.
2. Make a focused change.
3. Open a PR into `main`.
